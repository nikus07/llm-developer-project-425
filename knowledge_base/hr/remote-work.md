# Удалённая и гибридная работа

## Форматы работы
- **Офисный формат** — присутствие в офисе 5 дней в неделю.
- **Гибридный формат** — минимум 2 дня в неделю в офисе, остальные — удалённо, по согласованию с руководителем.
- **Полностью удалённый формат** — доступен для отдельных ролей по решению руководителя направления и HR-директора, оформляется дополнительным соглашением к трудовому договору.

## Как перейти на гибридный формат
1. Сотрудник обсуждает формат работы с руководителем.
2. Руководитель подтверждает согласие в системе HR (портал → «Формат работы» → «Изменить формат»).
3. HR готовит дополнительное соглашение при переходе на полностью удалённый формат (для гибридного формата доп. соглашение не требуется).

## Требования при удалённой работе
- Обязательное подключение к рабочей почте и корпоративному мессенджеру в рабочие часы (09:00–18:00 по часовому поясу подразделения).
- Использование VPN при работе с внутренними системами компании (см. документ IT-002 «Доступ к корпоративному VPN»).
- Участие в обязательных синхронизациях команды (стендапы, ретро) по видеосвязи с включённой камерой.

## Компенсация оборудования для удалённой работы
Компания предоставляет ноутбук и, при необходимости, монитор и гарнитуру — заявка подаётся через IT Service Desk (см. документ IT-004 «Заявка на новое оборудование»). Компенсация домашнего интернета не предусмотрена.
